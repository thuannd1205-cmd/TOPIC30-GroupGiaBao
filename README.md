Yêu cầu
Python 3.10 – 3.12 (khuyến nghị).
Chạy ứng dụng: không cần GPU. Huấn luyện: nên có GPU NVIDIA hoặc dùng Google Colab/Kaggle.

mở Terminal thực hiện lần lượt các lệnh sau:
1: python -m venv venv (tạo môi trường ảo riêng cho dự án)
2: venv\Scripts\activate ( kích hoạt môi trường ảo)
3: python -m pip install --upgrade pip
4: pip install -r requirements.txt ( tải các thư viên cần thiết)
5: streamlit run app.py ( chạy chương trình)
